# macOS：Hammerspoon 中文英译

在可编辑文本框中翻译并替换选区或当前实际行；选中网页、文档等只读文字时，在选区旁显示可编辑的译文窗口。油猴版继续保留，两者可同时安装。

## 安装

1. 安装并运行 [Hammerspoon](https://www.hammerspoon.org/)。
2. 在 Hammerspoon Preferences 中检查 **Accessibility** 状态。若显示 **Accessibility is enabled. You’re all set!**，已获授权，无需重复开启；尚未授权时，再按提示进入 macOS 系统设置开启**辅助功能**权限。
3. 在项目根目录运行：

```sh
python3 hammerspoon/install.py
```

安装程序将独立模块复制到 `~/.hammerspoon/keyword_translator.lua`，并在 `~/.hammerspoon/init.lua` 末尾追加加载代码。已有配置保留，发生替换时创建带时间戳的备份。重复运行不会重复追加，也不会覆盖加载块里已修改的翻译快捷键。升级时会移除加载块中旧的 `undoModifiers` 和 `undoKey` 配置。可以用 `--directory /你的配置目录` 指定其他配置目录。

4. 在 Hammerspoon 菜单中选择 **Reload Config**。菜单栏出现 **中→EN** 即表示模块已加载。

如果不使用安装程序，也可以手动将本目录中的 `keyword_translator.lua` 复制到 Hammerspoon 配置目录，并在原 `init.lua` 末尾加入：

```lua
keywordTranslator = require("keyword_translator").new():start()
```

安装和运行无需 Node.js、API Key、浏览器开发者模式或额外的 Lua 解释器。翻译请求使用 macOS 自带的 `/usr/bin/curl`，不会执行 shell 命令。

## 使用

| 操作 | 默认快捷键 |
| --- | --- |
| 翻译选区／当前行 | **Control + Option + '** |
| 撤销替换 | 目标软件的 **Command + Z** |

输入法完成选词后再操作。按完快捷键请松开修饰键；超过 2 秒仍未松开时，本次替换取消。

- **可编辑文本框有选区：**翻译并替换选中部分，支持跨行。
- **选中只读文字：**在选区旁显示译文窗口，原文保持不变。窗口里的文本框可编辑，可用 **Command + C** 复制选中部分，或点击 **复制译文** 复制编辑后的全部内容；点击 **复制原文** 复制触发翻译时取得的原文，不受译文编辑影响；按 **Escape**、点击 **关闭** 或窗口关闭按钮结束预览。
- **可编辑文本框无选区：**翻译光标所在的实际行，以实际换行符分隔。自动折行仍算一行；单行输入框会处理整框内容。
- **空白或不含中文：**不请求翻译，也不回退为翻译整个文本框。
- **撤销：**使用当前软件的 **Command + Z**。模块不注册额外恢复快捷键，也不设置 12 秒恢复期限；撤销记录由目标软件管理。

保留选区外内容、换行、空行、缩进和首尾空白。待翻译部分最多 2000 个 UTF-16 单元，与油猴版的字符计数方式一致；emoji 一般占两个单元。译文分行结构不一致或仍含中文时保留原文。

等待译文期间，输入按键、鼠标操作、可检测到的文本或选区变化、焦点变化、应用禁用或暂停会阻止自动回填。模块会结合事件监听、可用的辅助功能通知和定期状态检查；无法保证捕获目标应用不公开的所有内部状态变化。

模块通过设置目标选区并粘贴译文实现替换，不赋值整个文档，也不主动按回车或发送消息。目标软件仍决定粘贴、富文本样式和撤销行为，需要逐个软件验证。

## 与油猴版一起使用

油猴版继续使用 **Ctrl + '**；本模块默认增加 **Option**，避免同时响应。油猴版源码和安装方式保留。

在 `init.lua` 的加载块中修改快捷键，例如只用 Control：

```lua
keywordTranslator = require("keyword_translator").new({
    translateModifiers = {"ctrl"},
    translateKey = "'",
}):start()
```

改成相同组合键时，请在对应浏览器中禁用其中一个版本，避免冲突。更改配置后 **Reload Config**。

## 不支持直接替换的编辑器

辅助功能接口是支持范围的依据，而不是软件名称。普通文本控件中能准确读取全文、光标和选区、且允许设置选区时，才自动替换。

对于网页正文、只读文本框，以及只能读取选中文字的编辑器，快捷键会打开**可编辑译文窗口**。优先放在选区附近；无法获取选区位置时放在鼠标附近，并限制在屏幕可用范围内。窗口可移动、调整大小，支持多行文字。打开、编辑或关闭窗口不会改动剪贴板；只有点击 **复制原文**、**复制译文** 或执行 Command + C 才复制内容。**复制原文** 直接通过 Hammerspoon 写入剪贴板，不触发原网页的复制事件；原文须能通过辅助功能接口读取。

选中文字通过当前辅助功能元素及其父级的 `AXSelectedText` 或文本标记接口读取，不模拟 Command + C 抓取原文，也不读取整页作为选区的替代。应用没有公开选中文字时仍需手动复制，不能保证所有软件都支持直接预览。

对于完全无法读取的编辑器，可以先手动复制需要翻译的文字，再点击菜单栏 **中→EN → 翻译剪贴板（仅预览）**。这项操作不自动粘贴，也不猜测当前行。

自定义富文本、聊天、文档编辑器，终端、远程桌面等不能保证通用。终端 Terminal 和 iTerm2 默认跳过，密码及可识别的受保护控件、安全输入状态也会排除。设置选区后最多等待 0.6 秒，核对读取到的范围再粘贴，兼容 Chromium 延迟更新选区的情况。已有选区正确时直接使用，不重复设置。无法确认选区或粘贴结果时会提示，不重复粘贴。

## 菜单与隐私

菜单栏 **中→EN** 提供暂停／继续翻译，以及按当前应用禁用／启用。禁用设置只保存应用 Bundle ID，不保存输入文字或译文。

只有手动触发后才发送本次目标文本到 `translate.googleapis.com`。免费接口没有稳定性保证，可能限流或改变；需要能够访问 Google 翻译的网络。请求不使用 Cookie，不跟随重定向，12 秒网络超时，不自动重试。文字通过子进程标准输入传入，不出现在命令行参数中。

粘贴前临时备份剪贴板第一项的可读取格式，完成检查后恢复；如果此时剪贴板已被其他操作更新，会保留新的内容。为避免丢失其他项目，剪贴板包含多个项目时不会自动替换。剪贴板管理器仍可能记录临时译文。预览窗口使用本机 WebKit，不加载外部页面，也不保存输入和译文。窗口中的“复制原文”复制本次捕获的原文，“复制译文”复制编辑后的全文；这两项都是明确的复制操作，不恢复旧剪贴板。

## 故障排查

- **快捷键无反应：**先确认已 Reload Config、出现“中→EN”菜单，以及辅助功能权限已开启。检查快捷键冲突和输入法选词状态；权限改变后必要时重启 Hammerspoon。
- **提示无法读取：**该编辑器的辅助功能支持不足。选中文字后再试，或使用手动复制、菜单翻译预览。
- **Google 翻译限流／网络错误：**原文不会被替换，稍后手动重试。
- **提示无法确认粘贴结果：**检查文本框内容，不要立即重复触发；软件可能拒绝或延迟处理粘贴，需要专门适配。
- **提示选区无法设置：**这不是辅助功能权限未开启的结论。目标编辑器可能不支持写入选区；先手动选中文字再试。
- **撤销：**在原文本框按 **Command + Z**；具体行为由软件的撤销历史决定。

## 升级或卸载

更新仓库后重新运行安装程序，再 **Reload Config**。卸载时删除 `init.lua` 中由 `BEGIN keyword-translator` 和 `END keyword-translator` 标记包围的加载块，以及 `keyword_translator.lua`，然后重新加载。其他配置保留。

## 验证

```sh
npm test
npm run test:hammerspoon
```

Node.js 检查包含安装备份、原配置保留与重复安装。Lua 检查使用模拟 Hammerspoon／macOS 接口验证业务流程；优先使用系统 Lua 5.3+，本机未安装 Lua 时可使用 Hammerspoon 自带 Lua 库。它们不能代替具体软件中的实际测试。

另有 `tools/hammerspoon-native-check.mjs` 用于原生回填测试，需要已授权的 Hammerspoon 实例在 Console 临时运行 `require("hs.ipc")`，并提供 `PLAYWRIGHT_MODULE` 和 `BROWSER_EXECUTABLE`。测试会打开带临时配置的浏览器窗口，使用自建文本框和已知译文验证实际 AX 选区、粘贴、剪贴板恢复与 Command + Z；不会读写日常浏览器页面。运行时请暂停键盘和鼠标操作，结束后 Reload Config 关闭临时 IPC 接口。它不验证真实翻译网络服务。

`tools/hammerspoon-preview-native-check.mjs` 使用相同环境变量，实测网页正文及只读 textarea 的选区读取、原生译文窗口、真实键盘编辑、原文和译文复制按钮、网页复制事件绕过、原文换行与 emoji 保留、按钮布局、关闭及 HTML 字符安全显示；只模拟翻译响应。

接口依据：[文本访问](https://www.hammerspoon.org/docs/hs.axuielement.html)、[键盘事件](https://www.hammerspoon.org/docs/hs.eventtap.html)、[剪贴板](https://www.hammerspoon.org/docs/hs.pasteboard.html)。
