# 自用方案：Tampermonkey 脚本

适用于新版 Chrome 和 Brave。无需发布你自己的扩展，无需注册商店开发者账号。通过商店安装现成的 Tampermonkey，再启用它的“允许用户脚本”即可使用。

Tampermonkey 5.3+ 的官方说明：基于 Chrome 的浏览器，在 Chrome 138+ 中，可以开启扩展详情里的 **Allow User Scripts / 允许用户脚本** 来授予脚本执行权限，无需保持全局开发者模式开启。参考 [官方 FAQ](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。若你的浏览器没有此开关，请更新浏览器和 Tampermonkey。

## 安装

1. 在 [Tampermonkey 官方 Chrome 下载页面](https://www.tampermonkey.net/index.php?browser=chrome)点击 **Get from Store**，从 Chrome Web Store 安装稳定版 Tampermonkey。Brave 也可以使用这个商店版本。
2. 打开 `chrome://extensions` 或 `brave://extensions`，找到 **Tampermonkey → 详情**，开启 **允许用户脚本 / Allow User Scripts**。全局“开发者模式”可以关闭。
3. 点击浏览器工具栏的 Tampermonkey 图标，选择 **添加新脚本 / Create a new script**。
4. 用文本编辑器打开旁边的 `google-keyword-translator.user.js`，复制整个文件内容。选中油猴编辑器内原有的模板，全部替换为复制的内容。
5. 按 **Ctrl + S** 保存（Mac 使用 **Command + S**），确认脚本已启用。
6. 如果之前安装过本项目的独立扩展，在扩展管理页将它关闭，以免两个版本同时响应快捷键。
7. 刷新 Google / Google Scholar 页面。

不需要开启“允许访问文件网址”，也不需要将脚本发布到任何网站。若油猴首次询问联网权限，允许脚本连接 `translate.googleapis.com`。

## 使用

在 Google / Google Scholar **网页里的搜索框**输入中文，完成输入法选词后，按 **Control + '**（Mac 也使用 Control）。脚本把整个搜索框中的中文或中英混合关键词翻译为英文，再按回车搜索。替换后右下角有“恢复中文”按钮，显示 12 秒。

失败会保留原文；翻译期间修改文本或移走焦点，译文不会直接覆盖当前输入。它只在按快捷键时发送关键词到 Google 翻译，不保存搜索词。免费接口需要联网，可能限流或改变；复杂搜索语法和学术术语需要核对。

## 开发

此单文件脚本从原扩展的共享配置和搜索框脚本生成，转换其请求通道为 Tampermonkey 的 `GM_xmlhttpRequest`。运行 `npm run build:userscript` 可重新生成。安装使用无需 Node.js。
