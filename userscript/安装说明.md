# Tampermonkey 脚本安装说明

适用于 Chrome 和 Brave。通过商店安装 Tampermonkey，再启用它的“允许用户脚本”。无需注册商店开发者账号或发布自己的扩展。

Tampermonkey 5.3+ 的 [官方 FAQ](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)说明：Chrome 138+ 的 Chrome 系浏览器可开启扩展详情中的 **Allow User Scripts / 允许用户脚本**，全局“开发者模式”可以关闭。没有此开关时，请更新浏览器和 Tampermonkey。

## 安装或升级

1. 在 [Tampermonkey 官方下载页面](https://www.tampermonkey.net/index.php?browser=chrome)点击 **Get from Store**，从 Chrome Web Store 安装稳定版 Tampermonkey。Brave 也可使用该版本。
2. 打开 `chrome://extensions` 或 `brave://extensions`，找到 **Tampermonkey → 详情**，开启 **允许用户脚本 / Allow User Scripts**。
3. 首次安装时，点击 Tampermonkey 图标，选择 **添加新脚本 / Create a new script**。升级时，在管理面板中打开原来安装的脚本。
4. 打开 [google-keyword-translator.user.js](google-keyword-translator.user.js)，复制整个文件，全部替换油猴编辑器中的原有代码。
5. 按 **Ctrl + S** 保存（Mac 使用 **Command + S**），确认脚本已启用。只启用这一份脚本，避免旧版本重复响应。
6. 如果之前加载过本项目的独立扩展，请将它关闭或移除。
7. 刷新需要使用的网页。若油猴询问联网权限，允许连接 `translate.googleapis.com`。

无需开启“允许访问文件网址”。脚本现会在普通 HTTP / HTTPS 网站运行，而不再限定 Google 和 Google Scholar。

## 使用规则

在网页文本框中输入中文，完成输入法选词后，按 **Control + '**（Mac 也使用 Control）。

- **选中文字：**只翻译并替换选中部分，支持跨多行；选区外内容保留。
- **没有选区的多行文本框：**只翻译光标所在的实际行，以换行符分隔。自动折行不影响范围，空白或英文行不处理。
- **没有选区的单行输入框：**翻译整个输入框。

保留换行、空行、缩进和首尾空白；返回的分行结构不一致时保留原文并提示。每次目标最多 2000 个字符。替换后右下角显示 **恢复原文** 按钮，持续 12 秒。

等待期间修改文字、改变光标或选区、移走焦点，会取消回填。失败会保留原文；恢复原文不会覆盖后续修改。脚本不会提交搜索或发送消息。

通过 Tampermonkey 图标菜单可以 **在此网站禁用中文英译**，或再次启用。只保存禁用网站的主机名，不保存输入内容。只有按快捷键时，本次选区或当前行才会发送到 Google 翻译。该免费接口需要联网，可能限流或改变。

## 范围与限制

支持普通网页的文本输入框、搜索框和 `textarea`，包括动态输入框及开放 Shadow DOM 中的输入框。密码、数字、只读和禁用字段不会处理；可识别的验证码、付款和凭据字段也会排除。

浏览器地址栏、内部页面、iframe、封闭 Shadow DOM、富文本 `contenteditable` 及自定义聊天或文档编辑器暂不支持。部分网站的输入状态管理还需专门适配；不是所有网站的文本输入界面都能直接修改。

## 开发

脚本由 `config.js`、`transport.js` 和 `content.js` 生成。在项目根目录运行 `npm run build` 或 `npm run build:userscript` 重新构建。安装和使用无需 Node.js。开发修改后，需要替换 Tampermonkey 中的已安装代码，保存并刷新网页。
